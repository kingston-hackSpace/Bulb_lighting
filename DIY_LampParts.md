# DIY LAMP - PARTS
----
This document provides guidance on the parts required to build a DIY lamp wired to mains electricity, following hackSpace advise. 

This is a PART LIST ONLY, with suggested purchasing links. 

**Assembly must be carried out by a hackSpace technician** and PAT tested by KU electricians prior to use. 

Please **book a hackSpace Wiring Sockets Consultation** before you buy any equipment. 

⚠️ *Wiring to mains electricity is extremely dangerous. Incorrect wiring can cause **electrocution or fire**. Do not attempt to assemble or wire any part of this project yourself.*
